# DayZ OGG Converter

Программа конвертирует **MP3 (и WAV, FLAC, M4A, AAC, WMA, OPUS, OGG)** в **OGG Vorbis** для DayZ
и сразу генерирует `config.cpp` с `CfgSoundShaders` и `CfgSoundSets` под полученные файлы.

Есть графический интерфейс и консольный режим. Файлы конвертируются пакетно в несколько потоков.

## Возможности

- Пакетная конвертация файлов и целых папок (с подпапками, структура сохраняется).
- Пресеты: 3D-звук (моно), музыка/радио (стерео), UI/2D, петля эмбиента, выстрел.
- Моно или стерео, 22050/32000/44100/48000 Гц, качество Vorbis от −1 до 10.
- Нормализация по пику (dBFS) или по громкости (LUFS, EBU R128), ручное усиление.
- Обрезка тишины в начале и конце, fade-in и fade-out, вырезка фрагмента (начало и длительность).
- Безопасные имена файлов: транслитерация кириллицы, нижний регистр, только `a-z0-9_`.
  Например, `Выстрел АК-74.mp3` становится `vystrel_ak_74.ogg`.
- Генерация `config.cpp`: `CfgPatches`, `CfgSoundShaders`, `CfgSoundSets` (3D или 2D, loop, дальность,
  громкость). На вкладке «config.cpp» есть предпросмотр с копированием.
- Из файлов удаляются метаданные и обложки, запись идёт во временный файл (битых `.ogg` не остаётся).
- Настройки сохраняются между запусками.

## Готовая программа (рекомендуется)

`DayZOggConverter.exe` — один файл для Windows 10/11. **Ничего устанавливать не нужно**: Python и ffmpeg
(с кодеком Vorbis) уже внутри. Скачайте и запустите, аудиофайлы можно перетаскивать прямо на `.exe`.

Где взять:
- раздел **Releases** репозитория, релиз `ogg-converter-latest`;
- или вкладка **Actions** → «DayZ OGG Converter (Windows exe)» → артефакт `DayZOggConverter`.

Этот `.exe` автоматически собирается на Windows после каждого изменения в папке `DayZ_OggConverter/`.
Перед публикацией сборка проходит проверку: конвертация тестового MP3 и запуск интерфейса.

При первом запуске Windows SmartScreen может предупредить о неизвестном издателе, потому что у файла нет
цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

Консольный режим работает и у `.exe`:
`DayZOggConverter.exe --cli "D:\sounds" -o "P:\MyMod\sounds" --config --mod MyMod`
(вывод в консоль не печатается, результат смотрите в папке вывода).

## Запуск из исходников (Windows)

1. Установите [Python 3.8+](https://www.python.org/downloads/) и при установке отметьте «Add python.exe to PATH».
2. Скачайте ffmpeg, например `ffmpeg-release-essentials.zip` с https://www.gyan.dev/ffmpeg/builds/.
   Возьмите из архива `bin\ffmpeg.exe` и положите рядом с `dayz_ogg_converter.py`.
   Вместо этого можно выполнить `pip install imageio-ffmpeg` или добавить ffmpeg в PATH.
3. Запустите `run.bat`.

Программа ищет ffmpeg в таком порядке: путь из настроек → рядом с программой (`ffmpeg.exe`, `ffmpeg\bin\ffmpeg.exe`)
→ PATH → пакет `imageio-ffmpeg`.

### Сборка одного .exe

Положите `ffmpeg.exe` рядом со скриптом и запустите `build_exe.bat`. Получится `dist\DayZOggConverter.exe`
со встроенным ffmpeg, и Python для его запуска не понадобится. Аудиофайлы можно перетаскивать прямо на `.exe`.

## Как пользоваться (интерфейс)

1. Нажмите «+ Файлы» или «+ Папка».
2. Выберите пресет. Для звуков в мире (шаги, выстрелы, предметы) выбирайте **моно**.
3. На вкладке «Вывод» укажите папку. Если её не указать, файлы попадут в подпапку `ogg`.
4. На вкладке «config.cpp» укажите имя мода и **путь в PBO**, куда положите звуки, например `MyMod\sounds`.
5. Нажмите «▶ Конвертировать».

## Консольный режим

```bat
python dayz_ogg_converter.py --cli "D:\sounds" -o "P:\MyMod\sounds" -p "3D звук (моно)" ^
    --normalize peak --trim-silence --config --mod MyMod --sound-path "MyMod\sounds" --range 100
```

Основные ключи (полный список выводит `--help`):

| Ключ | Что делает |
|---|---|
| `-o PATH` | папка вывода |
| `-p ПРЕСЕТ` | пресет |
| `--mono` / `--stereo` | число каналов |
| `-r 44100` / `-q 6` | частота и качество |
| `--normalize none\|peak\|loudness` | нормализация (`--peak -1`, `--lufs -16`) |
| `--volume dB` | усиление |
| `--trim-silence`, `--fade-in`, `--fade-out` | обработка |
| `--start`, `--duration` | вырезать фрагмент (сек) |
| `--flat`, `--prefix`, `--no-sanitize`, `--no-overwrite` | имена и структура |
| `--config --mod X --sound-path X\sounds` | сгенерировать config.cpp |
| `--range`, `--loop`, `--no-spatial`, `--class-prefix` | параметры SoundShader/SoundSet |
| `-j N` | число потоков |

## Как подключить звук в мод

1. Положите `.ogg` в `P:\MyMod\sounds\` (путь должен совпадать с «Путь в PBO»).
2. Добавьте сгенерированный `config.cpp` в мод или перенесите из него классы в свой конфиг.
3. Соберите PBO. Расширения `.ogg` в `samples[]` не указывается, так и должно быть.
4. В скрипте:

```c
// 3D-звук в точке
EffectSound snd = SEffectManager.PlaySound("MyMod_vystrel_ak_74_SoundSet", GetPosition());
snd.SetSoundAutodestroy(true);

// на объекте
SEffectManager.PlaySoundOnObject("MyMod_vystrel_ak_74_SoundSet", this);
```

## Советы для DayZ

- **Моно** нужно для всех позиционных 3D-звуков: стерео-файл в 3D звучит некорректно.
  Стерео подходит только для 2D (UI, музыка в меню).
- **44100 Гц** — стандартная частота для игровых звуков.
- Качества 5–7 хватает. Выше 8 размер растёт, а разница почти не слышна.
- Нормализуйте короткие эффекты по пику (−1 dBFS), а музыку и эмбиент по громкости (−16…−20 LUFS).
  После сжатия в Vorbis пик может вырасти на доли дБ, поэтому для громких звуков ставьте цель −1.5…−2 dBFS.
- Для зацикленных звуков не используйте fade, иначе в месте склейки будет «провал».
