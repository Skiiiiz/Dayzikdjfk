# Boogy_BattlePass — боевой пропуск для DayZ

Сезонный боевой пропуск: задания, уровни, бесплатные и премиум-награды, магазин кейсов,
интеграция с донат-системами через HTTP. Все параметры — в JSON-конфигах.

## Возможности

**Сезоны**
- Даты начала и окончания (`StartDate` / `EndDate`) с учётом часового пояса.
- Автоматическая смена сезонов без участия администратора (проверка каждые 30 секунд,
  игроки получают уведомление и обновлённое меню).
- Любое количество сезонов — каждый в отдельном файле `Seasons\*.json` со своими заданиями и наградами.
- После окончания сезона награды можно забрать до начала следующего (`AllowClaimAfterSeasonEnd`).

**Задания**
- `Kill` — убийства зомби, животных или игроков; условия по классу цели, оружию, дистанции, зоне, количеству.
- `Action` — любые игровые действия: лечение, костры, строительство, еда, использование предметов и т.д.
  (по классу действия и предмету в руках).
- `Craft` — крафт предметов (по классу результата или рецепта) с указанием количества.
- `Visit` — посещение точек/зон: `Any` (любая точка), `All` (все точки), `Route` (маршрут по порядку).
- `Custom` — пользовательские события от других модов (`BBP_API.ReportEvent`).
- Периоды: `Season`, `Daily`, `Weekly` (автосброс прогресса), премиум-задания (`PremiumOnly`).

**Награды**
- Бесплатная и премиум-ветка на каждом уровне.
- Типы: `Item` (любые предметы, с количеством, наполненностью, здоровьем и вложениями),
  `Coins`, `Xp`, `Case`, `Premium`, `Custom` (обрабатывается другими модами).
- Кнопка «Забрать всё» или автовыдача (`AutoClaimRewards`).

**Премиум-доступ**
- Активация специальным предметом `BBP_PremiumPass` (или любым классом из `PremiumItems`).
- Выдача через донат-API (HTTP), админ-команды или API других модов.
- Отдельные задания, награды и кейсы только для премиума.

**Интерфейс** — меню по клавише **J** (меняется в настройках управления): уровень, опыт,
таймер сезона, награды по уровням, задания с прогрессом, магазин кейсов.

**Магазин кейсов** — покупка за монеты пропуска или за предметы-валюту из инвентаря,
взвешенные шансы выпадения, отображение шансов в меню.

## Структура

```text
Boogy_BattlePass/
  config.cpp               — CfgPatches / CfgMods / предмет BBP_PremiumPass
  inputs.xml               — клавиша меню (UABBPMenu, по умолчанию J)
  Scripts/3_Game           — константы, конфиги, данные, клиентское состояние, даты
  Scripts/4_World          — серверный менеджер, хуки событий, действие активации, API
  Scripts/5_Mission        — MissionServer/MissionGameplay, меню, команды чата
  GUI/layouts              — разметка меню (генерируется TOOLS/gen_layouts.py)
  Examples                 — примеры конфигов
  Docs                     — документация
```
