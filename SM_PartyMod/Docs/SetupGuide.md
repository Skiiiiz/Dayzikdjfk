# SM_PartyMod - установка на сервер

Гайд для владельца сервера. Здесь только то, что нужно для установки и запуска.

## Что ставить

Нужен мод `SM_PartyMod` на сервере и у игроков.

Если мод выдается как готовая папка, обычно она называется:

```text
@SM_PartyMod
```

Если мод упаковывается вручную, в релизной папке должны быть:

```text
@SM_PartyMod\addons\*.pbo
@SM_PartyMod\keys\*.bikey
```

Файл `.bikey` нужно положить в папку `keys` сервера.

## Быстрая установка

1. Остановите сервер.
2. Загрузите папку `@SM_PartyMod` в корень сервера.
3. Скопируйте `.bikey` в папку `keys` сервера.
4. Добавьте мод в параметры запуска.
5. Запустите сервер один раз.
6. После первого запуска появится конфиг:

```text
$profile\SM_PartyMod\Settings.json
```

7. Остановите сервер.
8. Настройте `Settings.json`.
9. Запустите сервер снова.

## Параметры запуска

Пример:

```text
-mod=@SM_PartyMod
```

Если у вас есть другие моды, оставьте их как были и добавьте `@SM_PartyMod` в общий список.

Пример:

```text
-mod=@CF;@Trader;@SM_PartyMod
```

Если сервер не использует CF или другие зависимости, добавлять их специально не нужно.

## Где лежат файлы мода

После запуска мод создает папку:

```text
$profile\SM_PartyMod
```

Основной конфиг:

```text
$profile\SM_PartyMod\Settings.json
```

Данные игроков и кланов:

```text
$profile\SM_PartyMod\Clans
$profile\SM_PartyMod\Achievements
$profile\SM_PartyMod\Market
$profile\SM_PartyMod\ServerMarket
$profile\SM_PartyMod\Auction
$profile\SM_PartyMod\Storage
```

## Как правильно менять конфиг

1. Остановите сервер.
2. Сделайте копию файла `Settings.json`.
3. Измените нужные параметры.
4. Проверьте, что JSON не сломан: кавычки, запятые, скобки.
5. Запустите сервер.

Если параметр указан неправильно, мод может заменить его безопасным значением при старте.

## Что не настраивается на сервере

Эти вещи игрок настраивает сам в меню мода:

- прозрачность чата;
- количество строк чата;
- история чата;
- положение чата;
- положение HUD клана;
- компактный HUD;
- показ себя в HUD;
- дистанция скрытия HUD-меток;
- дистанция скрытия пингов;
- включение 3D-меток на клиенте.

На сервере оставлены только общие правила: включить/выключить систему, лимиты, награды, рынок, аукцион, хранилище и так далее.

## Горячие клавиши по умолчанию

Игрок может поменять их у себя в настройках управления.

| Клавиша | Действие |
| --- | --- |
| `P` | Открыть меню клана |
| `M` | Открыть карту клана |
| `T` | Поставить быстрый пинг |
| `Y` | Очистить быстрые пинги |

## Обновление мода

1. Остановите сервер.
2. Сделайте копию `$profile\SM_PartyMod`.
3. Замените папку `@SM_PartyMod` новой версией.
4. Не удаляйте `$profile\SM_PartyMod`, если не хотите вайпнуть кланы, рынок, склад и достижения.
5. Запустите сервер.

`Settings.json` обновляется автоматически: новые параметры добавятся сами, старые данные кланов останутся.

## Полный вайп данных мода

Остановите сервер и удалите:

```text
$profile\SM_PartyMod
```

После запуска мод создаст чистый конфиг и пустую базу.

## Частичный вайп

Удаляйте только нужную папку:

| Папка | Что сбросится |
| --- | --- |
| `Clans` | кланы, участники, казна, базы, логи |
| `Achievements` | прогресс личных достижений |
| `Market` | рынок игроков |
| `ServerMarket` | текущая ротация серверного маркета |
| `Auction` | аукцион |
| `Storage` | клановое хранилище |

Перед удалением всегда делайте копию.

## Быстрая проверка после установки

После запуска зайдите на сервер и проверьте:

1. Открывается меню клана на `P`.
2. Создается клан.
3. Работает чат клана.
4. Работают пинги на `T`.
5. Открывается карта клана на `M`.
6. В `$profile\SM_PartyMod` появились файлы данных.

Если меню не открывается, проверьте:

- мод есть у клиента и на сервере;
- мод добавлен в `-mod`;
- ключ `.bikey` лежит в `keys`;
- клиент и сервер используют одну версию мода.
